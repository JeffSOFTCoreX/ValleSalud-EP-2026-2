# Funciones del Sistema ValleSalud

Carpeta destinada a almacenar la lógica funcional complementaria del prototipo.

## Contenido

- funciones.py:
  Contiene funciones de búsqueda, filtrado, consultas y generación de reportes.

- pruebas.py:
  Contiene las pruebas funcionales y validaciones realizadas para comprobar el funcionamiento del sistema.
