# ValleSalud EP 2026-2

Repositorio correspondiente al desarrollo del proyecto ValleSalud para el Entregable Parcial (EP) 2026-2.

Este repositorio contiene la documentación, código del prototipo, elementos de diseño, evidencias de funcionamiento y material de presentación del proyecto.

## Estructura del repositorio

- 01_Informes:
  Documentación del proyecto y entregables escritos.

- 02_Código:
  Archivos fuente correspondientes al desarrollo del prototipo.

- 03_Diseño:
  Elementos gráficos utilizados para representar la estructura del sistema.

- 04_Evidencias:
  Pruebas, capturas y resultados obtenidos durante la ejecución del prototipo.

- 05_Presentacion:
  Material utilizado para la sustentación del proyecto.
